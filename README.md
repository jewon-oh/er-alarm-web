## 주요 특징

- 직관적인 실적 발표일 정보 시각화
- 사용자 맞춤형 알림 설정 및 관리 기능


## 설치 및 실행

1. 저장소 클론
   ```bash
   git clone https://github.com/jewon-oh/er-alarm-web.git
   cd er-alarm-web
   ```
2. 의존성 설치
   ```bash
   yarn install
   ```
3. 개발 서버 실행
   ```bash
   yarn dev
   ```
   (브라우저에서 `http://localhost:3000`으로 접속합니다.)

4. Docker Compose를 이용한 실행 (권장)
   ```bash
   docker-compose up --build -d
   ```
   (백그라운드에서 웹 서비스가 실행됩니다.)

5. 서비스 중지
   ```bash
   docker-compose down
   ```
